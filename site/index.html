01 — The browser

Built for the Mac, not ported to it.

No Electron and no Chromium. Axolotl uses the same engine as Safari, so it looks, scrolls and saves battery like the rest of your Mac.

Native and quick

Written in Swift with SwiftUI, on WebKit. Opens fast and stays light on memory.

02 — A closer look

Five ways it gets out of your way.

  1. i.

    Tabs along the top

    Classic tabs beside the window buttons, or one compact row. Drag a tab into another window to move it there.

  2. ii.

    Or down the side

    Prefer a sidebar? Pinned tabs, favorites and today's tabs sit in one tidy vertical list.

  3. iii.

    Two pages, one window

    Drop one tab onto another to read them side by side. Drag the divider to resize.

  4. iv.

    Ask about this page

    Press ⌘E and Axolotl opens beside the page. Summarize it, explain it, or pull in more tabs and files.

  5. v.

    A start page that stays quiet

    Type to search Google. When you want an answer instead, ⌘↩ asks Axolotl.

04 — Get it

Three steps. No account.

i.

Download

Grab Axolotl.dmg from the latest release.

ii.

Drag to Applications

Open the disk image and drag Axolotl into your Applications folder.

iii.

Open it

The first time, macOS can't verify Axolotl. Go to System Settings › Privacy & Security and click Open Anyway.

build from source
$ git clone https://github.com/RINNECODER/axolotl.git
$ cd Axolotl && ./scripts/setup.sh
$ open Axolotl.xcodeproj

Needs Xcode 26. Set your Apple Team ID in Signing.xcconfig first. The README has the details.
